# questward.tech

The Questward parent-company site. One static page, no build step.

`index.html` is the whole site. `CNAME` tells GitHub Pages which domain serves it —
deleting that file silently drops the custom domain, so leave it alone.

Ventures are grouped by sector rather than listed flat, because the page has to read
as well at twenty ventures as it does at four. Adding one means copying an `article`
block into the right sector.
